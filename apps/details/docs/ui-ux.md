# Details: UI and UX

Taken from the product demos on vitalsmac.com, read 1 November 2026. The site labels those demos as simulated, so they show intent and may differ from the real app. Local captures are in `references/current/`. `references/earlier/` holds September captures, from when the app had only eight tabs.

Colours and layouts are described so we can design our own version. Do not copy Vitals' artwork, icons or wording.

Mockups of these screens are in [mockups/index.html](mockups/index.html), generated by `mockups/build-mockups.mjs`. They use sample data. They replace the Overview rings with segmented bars, because close values are easier to compare that way. Agents keeps its plan rings.

## Principles

1. **Answer "which app?" first.** Every number leads to the app behind it.
2. **One glance, one click, one window.** The menu bar answers most questions, the dropdown answers more, and the window has everything.
3. **Silent until it matters.** A reading goes red first, and a notification comes only for a sustained pattern.
4. **Nothing closes without a yes.** Every confirmation says what will close and what that frees.
5. **Plain language.** "Runs out in 4 days at this rate", not a raw ratio.
6. **Honest gaps.** Say "unavailable" and why. Never show a false zero.
7. **Every number has a time.** Each CLI and MCP answer says when it was measured.

## Surfaces

| Surface | Purpose |
|---|---|
| Menu bar items | One or several readings, always visible |
| Dropdown | Compact copy of the window, opens from any item |
| Main window | All tabs, charts, tables and the inspector |
| Inspector drawer | Details on an app or process, beside the table |
| Notification | Sustained misbehaviour only |
| Approval window | An assistant's request to quit something |
| Settings | General, Layout, Customize, Insights, Integrations, About |
| Terminal | Same answers as the window |

## Main window

- Dark by default, with a light option. Traffic lights top left. A pill-shaped tab bar sits in the title bar, with an icon and label per tab.
- Tab order: Overview, CPU, Memory, Disk, Network, GPU, Neural, Battery, Sound, Bluetooth, Projects, Agents, Containers.
- Tabs for missing hardware or services do not appear: Battery, Neural and Containers.
- The selected tab uses its subsystem colour as a tinted pill.

### Colour per subsystem

Each subsystem's colour appears on its label, chart, bars and icon chip.

| Subsystem | Colour |
|---|---|
| CPU | Blue |
| Memory | Purple |
| Disk | Amber |
| Network | Green |
| GPU | Pink-red |
| Battery | Green |
| Sound | Magenta |
| Projects | Orange |
| Agents | Violet |
| Strain or running out | Red |

Exact values and the Neural, Bluetooth and Containers colours are still to choose. Network and Battery are both green in the reference, and we may want to separate them.

### Overview layout

- A 3-column grid of rounded cards. Each has an icon chip and label, a chevron to its tab, a caption, a big number with a smaller unit, three small stats, and a bar-style history strip.
- Status appears as a small pill, such as the green "Normal" for memory pressure.
- Under the cards: rings with a centre total and a legend, for memory by type, memory by app, and power by app.

### Subsystem tab layout

From top to bottom:

1. **Hero card.** "Now", a big figure, a couple of stats on the left, and a large area chart on the right.
2. **Stat row.** Four cards, such as User, System, Cores (with `8 P` and `4 E` chips), and Top App.
3. **App table.** Icon, name, "96 processes" underneath, a number, and a thin bar in the subsystem colour. Sorted, with the top row highlighted.

### Over Time and Peaks

- A segmented range control (1 h … 1 y) and a metric control (CPU, Memory, Energy, Disk, Network).
- Bars for the period, then "Used the most, by the hour" with ranked bars.
- Peaks is a grid of tiles with value and timestamp. At a Limit lists stretches below it.

### Inspector

- Opens beside the table so nothing is covered. The reference shows two panels side by side, app on the left and process on the right.
- **App panel:** large icon, name, process count, share and close. Memory and CPU tiles, smaller Power, GPU, Disk and Network tiles. A key-value details block with a green check by a valid signature and pills such as `Hardened Runtime` and `Not Sandboxed`. Then a folded Info.plist with a count, Processes, Show All, and Ended Recently.
- **Process panel:** Identity, App, Security, Resource Usage, Environment.
- Keys are right-aligned and values left-aligned. Linked processes are blue. Paths and arguments are monospaced.
- CPU time is a two-colour split bar with user and system legends. Memory is a bar against lifetime peak.
- Sensitive or long sections stay folded.

To avoid confusion with the product name, call the Vitals "Details card" the **App card**.

### Projects

- A banner across the top when servers are idle: "4 dev servers are running but idle. Stopping them frees 1.37 GB and ports 3000, 4321, 4322, 8000", with a Stop All… button.
- Each row has a folder icon, the name, the runtime or process count, orange port chips, a status pill ("working", "up 3 days, barely used", "idle 45 min"), and memory.

### Agents

- A strip of plan rings: percent inside, provider, window, then pace or reset. "Runs out in 4d at this rate" appears in red.
- Session cards: agent mark, title, a green "Working" pill, "Claude Code · storefront · running 48 min", memory, "Started · 4" with its children, and Quit Session….

### Sound

- An output strip with device picker, slider and percent.
- A microphone strip with "Listening right now" and the app.
- A table of App, Status, Volume and Level. Playing apps come first, and muted apps say Muted.

## Menu bar

- Items sit in a row, such as `36%`, `85%`, `↓4 kB/s ↑6 kB/s`, `53°`.
- Style options: Value, Graph, Both, Framed. The icon is optional. There is a compact size.
- Strain turns the item's icon and value red until it passes.

## Dropdown

- A rounded dark panel attached to the item, about 370 pt wide, judging by the reference.
- Top: an icon-only tab strip. Next: the section title, with uptime on the Overview.
- **Overview, tiles:** a 2-column grid with a figure and sparkline or bar. Then Busiest Right Now, then the footer.
- **Overview, list:** one line per reading.
- **Detail page:** figure with sparkline, key-value rows, Top Apps with bars.
- Footer: Open Details (wide), Settings, Quit. Open goes to the window on the current tab and closes the dropdown.
- While a reading is red, the top line says, for example, "CPU under strain · 94% for 6 min".

## Confirmations

Every quit, stop or Stop All says:
- the target, in plain words
- how many processes close
- the memory and ports freed
- what else is connected, if known

Force Quit is separate and never the default. A plain Quit lets the app ask to save its work.
