# Details

A Mac activity monitor that shows apps instead of processes, and names the app behind every number. It lives in a window and the menu bar, keeps history, warns about misbehaving apps, and understands dev servers, containers and coding agents.

Status: `wip`. Product plan only. No app code, and the stack is not chosen yet.

Details is modelled on the feature set and interaction design of [Vitals](https://vitalsmac.com). It is an independent app and does not use Vitals' name, artwork or text.
